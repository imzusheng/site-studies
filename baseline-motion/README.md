# BASELINE / Motion Build — v0.3.0

**状态：动作系统重构版；真实人物渲染尚未验收，不是“已达到 GTA5 品质”的完成品。**

这一版不再用球、柱体或方块拼接人物。游戏代码改用 Three.js 的真实 `SkinnedMesh`、贴图、关节链与蒙皮变形，移除了默认运行路径中的低精度人物替代。人物载入失败会明确提示，不会显示另一套简陋角色冒充成功。

## v0.3.1 命中修复（2026-09-12）

首次在真实蒙皮模型上运行后发现并修复了命中系统的几何硬伤：

- **计划触球点超出骨骼臂长**。Michelle 归一化后臂长仅约 0.55m（IK 极限 0.54m），而原计划触球点全部超出可达包络（准备姿势超 0.26m、腰高正手超 0.47m、发球超 0.61m），IK 会把拍面拉离来球——发球必挥空，击球只能靠轨迹碰巧重叠。现在触球深度跟随来球平面（身前 0.38–0.62m）、高度钳制 0.52–2.30m、横向最小偏移 0.24m，且拍面长轴沿“肩→触球点”方向，握把落在肩与球之间。
- **发球抛球**从 4.8m/s、身前 0.83m 改为 3.0m/s、身前 0.55m：触球点约 1.98m，在臂长范围内（旧抛球顶点 2.79m，几何上不可触及）。
- 挥拍自动补时窗口 ±75ms→±100ms，就绪提示窗口 90ms→120ms，IK 拉拽加 0.05m 容差。
- 回归工具 `tools/verify-hit.mjs`：用编译后的游戏逻辑与真实臂长做无头数值模拟。当前结果：发球 20/20，截击 5/5，底线击球在 ±120ms 释放时机内 4/5–5/5；浏览器实测连续 10 个喂球 10 次有效回球。

## 如何运行

### 联网 HTML

打开 `dist/baseline-motion.html`。第一次需要网络取得 Three.js、GLB 人物和可能使用的 Draco 解码器。使用支持 WebGL 2、ES modules/import maps 的桌面浏览器。

此文件不是离线自包含成品。若出现“无法完成载入”，说明引擎 CDN 或人物资源未成功取得；不是已经运行游戏。页面可重试。模型加载失败但引擎成功时，可选择本地兼容的 Mixamo 骨骼 GLB。

### 将依赖和人物放到本地

需要 Node.js 22 或以上及能访问 npm/模型下载源的网络：

```bash
npm install
npm run assets
npm run build:local
npm start
```

打开终端显示的 `http://127.0.0.1:4173`。本地构建内嵌引擎 JS 和 GLB 数据，Draco 文件位于 `dist/draco/`，因此应通过 HTTP 提供整个 `dist`，而不是把生成的 HTML 单独搬走并双击打开。

本执行环境无法下载依赖/人物，**没有实际运行 `build:local` 分支或验证人物最终画面**。提供的脚本不是已完成离线资产打包的证明。

普通源码构建与测试：

```bash
npm run build
npm test
```

`npm run build` 输出联网 HTML。测试读取已经生成的 `dist/game.js`，修改 TS 后先重新构建。

## 操作

- WASD：移动；Shift：短冲刺。
- Space：按住准备/蓄力，松开挥拍。发球同样操作。
- V：近距离动作检视；Esc：退出检视进入热身，或在游戏中暂停。
- 正反手不需要额外按键。系统在准备阶段持续判断来球侧，开始前挥后锁定本拍。

准备阶段换边做了位置与拍面方向过渡，避免瞬移。默认控制仍然不自动跑位、不自动挥拍、不吸球。可在场边设置开启鼠标微调回球方向。

## 这版的重点改动

### 人物链路

`src/human.ts` 使用 GLTFLoader、DRACOLoader、SkeletonUtils.clone 创建真正的蒙皮人物。它保留原模型贴图和网格，通过角色骨骼调整躯干、手臂、腿、踝、脚趾和手指。两个角色共用几何/贴图，拥有独立的骨骼实例。

当前默认资源是 Three.js 官方示例使用的 `Michelle.glb`。它是参考人物，不是定制网球运动员、GTA 人物，也不代表满足用户要求的最终精度和美术质量。**本包没有包含下载失败的 GLB 或任何 GTA 游戏资产。**

### 动作

`src/avatar.ts` 负责明确的准备、引拍、前挥、触球、随挥、回位阶段。正手在身体右侧引拍，随挥跨到另一侧；反手采用双手握拍目标。低来球会降低骨盆，转体分配给骨盆和脊柱，而不是只有球拍移动。

脚步区分支撑与摆动，包含脚跟着地、踝关节滚动、提踵、前脚掌蹬地、屈膝回收。支撑脚坐标保留在世界空间，不随角色平移。脚趾在推蹬阶段进行反向补偿。

这些是**手工程序化姿态轨迹 + 两段式 IK**，不是购买的专业网球动作捕捉，也不是已经调校完成的 AAA 动画库。脚跟/鞋底接触、关节自然度和任意姿态下的穿模，必须用真实模型继续做视觉检查。

### 命中

准备阶段根据预测来球侧调整正反手；出手后不在挥拍中途换边。预测触球时间用于小幅调整前挥长度，完整挥拍不被跳过。击球音和改变球速仍只在球与拍面扫描碰撞成立时触发。

手部 IK 以球拍握把为目标。实际骨骼够不到时会限制拍面位置，该位置同时参与可见球拍绘制与物理碰撞，不另设人物周围的大命中圈。**这项真实骨骼约束尚未在默认模型上运行验收；无模型的逻辑测试不能证明接入蒙皮后命中率不变。**

AI 提前引拍，不再等球落地才启动完整挥拍。原先七项训练与街机抢七规则保留。球拍调校仍是暂停菜单里的辅助功能。

### 动作检视

V / 顶部“动作检视”打开近距离观察。可切换正手、双手反手、高点挥拍、侧移、跑动，调整 0.15×–1× 播放速度与环绕角度。检视只播放动作，不模拟命中或打分；不是用于伪造成功触球的演示。

### 画面

默认 Three.js PBR、色调映射、柔和主光阴影与填充光、DPR 上限 2。关闭旧版持续低帧率自动降分辨率策略。降低并调整跟随镜头，给人物和脚部留出空间。没有实机帧率或最终视觉质量承诺。

## 代码入口

- `src/avatar.ts`：挥拍轨迹、姿态与脚步规划。
- `src/human.ts`：GLB、骨骼规范化、IK、手指及踝/趾关节。
- `src/game.ts`：固定时间步、自动选边、输入、AI、训练/计分、检视。
- `src/physics.ts`：轨迹、旋转、反弹、拍面连续碰撞和程序音效。
- `src/world.ts`：球场、镜头和场景绘制。
- `src/main.ts`：加载与模型替换；载入失败不会用方块替代。
- `template.html`：联网依赖加载器和 UI。
