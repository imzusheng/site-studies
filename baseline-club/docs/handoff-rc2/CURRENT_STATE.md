## 已定位的后续重点

`src/characters.js`：`apply`、`setAnimation`、`idle`、`armIK` 是角色专项入口。应保留用户认为自然的动作相位，先解决映射、手脚接触和变形，不重新用猜测旋转替换所有基础动作。

`src/physics.js`：`automatic` 当前直接构造 normal 与 racketVelocity，且 `abs(velocity.z)<5` 会施加保底速度。把它称作“物理启发式模式”更准确。真实拍面与拍头速度应来自相邻姿态采样，模拟与辅助层分开。

`src/app.js`：`getPlan`、`chooseAI`、`contact`、`stepBalls`、`updateHelpers` 是玩法改进入口。共享预测器是已有优势；不要为对手、玩家辅助和测试分别写三套飞行模型。
